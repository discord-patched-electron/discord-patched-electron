If Discord won't start

Close Discord completely, then run this in a terminal:

discord-canary-prerelease-patched-electron-bin --ignore-flags

For a tarball, use ./launch.sh --ignore-flags. Or set DPE_IGNORE_FLAGS=1. Presets, flag files and supplied arguments are skipped without deleting your settings.
