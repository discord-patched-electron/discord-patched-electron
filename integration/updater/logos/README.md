# Project logos

Settings shows these original project assets locally, without fetching images
when the window opens. They retain their original colors.

- `dpe.png` is copied during packaging from the repository's existing
  `discord-patched-electron.png` artwork, also used in the main README.
- `welcome-background.png` extends that artwork in Krita, with the original
  pixels preserved on a locked layer and separate sky and grass layers.
  Its editable source is [`artwork/welcome-background.kra`](../../../artwork/welcome-background.kra).
- `vencord.png` is the unmodified [Vencord website favicon](https://github.com/Vencord/Website/blob/149ba968a4a9c877869c8cee1741fb6d8489c6fe/public/assets/favicon.png).
  `vencord-dark.png` is its original [dark-theme variant](https://github.com/Vencord/Website/blob/149ba968a4a9c877869c8cee1741fb6d8489c6fe/public/assets/favicon-dark.png).
  The website's AGPL-3.0 license is included as `VENCORD-LICENSE.txt`.
- `equicord.png` is the unmodified [Equicord website icon](https://github.com/Equicord/Equibite/blob/1dca6e83e7a3b31317eb175d5db7e8f500e8a435/public/assets/icons/equicord/icon-128.png).
  The website's GPL-3.0 license is included as `EQUICORD-LICENSE.txt`.

The PNGs are the original image sources. Their use identifies the corresponding
projects and does not imply endorsement.
